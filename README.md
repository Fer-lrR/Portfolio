# ⚡ Luis Fernando Romano — Portfolio Web (SPA Jamstack)

Portfolio profesional interactivo desarrollado con **React 19, TypeScript y Vite**, enfocado en alto rendimiento, arquitecturas serverless y telemetría en tiempo real.

---

## 🛠️ Stack Tecnológico

- **Frontend Core:** React 19, TypeScript, Vite
- **Estilos:** Vanilla CSS Modular + Dark Theme Design System
- **Animaciones & Dinámica:** Framer Motion, Canvas Confetti
- **Iconografía:** Lucide React & Vector SVG
- **Despliegue:** Netlify / Cloudflare Pages

---

## 🚀 Instalación y Uso Local

```bash
# 1. Clonar el repositorio
git clone <URL_DEL_REPOSITORIO>

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor de desarrollo
npm run dev

# 4. Compilar para producción
npm run build
```
